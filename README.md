# The House of Earthmonk

A premium, bespoke reservation and management platform built for modern dining experiences.

## 🚀 Overview

The House of Earthmonk is a sophisticated web application designed to streamline the guest journey, from real-time table booking to administrative oversight. Rooted in mindful design and technical precision, this platform offers a seamless experience for both guests and management.

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS, Framer Motion (for smooth animations)
- **Backend**: Firebase (Authentication, Firestore, Storage)
- **UI Components**: shadcn/ui

## 📖 Key Features

- **Real-time Reservation System**: Precise time-slot booking with live availability.
- **Admin Dashboard**: Comprehensive control over tables, reservations, and real-time IST monitoring.
- **Precise Auditing**: Full lifecycle tracking (Requested, Approved, Arrived, Completed, Freed).
- **Pro Analytics**: Professional CSV data export for operational insights.

## 💻 Getting Started

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
